pretext + HarfBuzz

Text measurement without a browser. pretext lays out the lines; HarfBuzz measures the words, straight from the font file. The browser and Node run the same code and get the same layout.

How it works

  1. pretext asks a canvas how wide each word is. Node has no canvas, so pretext needs a browser.
  2. pretext-harfbuzz answers that question with HarfBuzz instead. HarfBuzz reads the font file and returns the width. It is the text shaper Chrome and Firefox use, here compiled to WebAssembly.
  3. So pretext works anywhere: in the browser, in Node or in a worker, with the same numbers everywhere. 
import { readFile } from "node:fs/promises";
import { measureLineStats, prepareWithSegments } from "@chenglou/pretext";
import { FontBook, installHarfBuzzMeasurer } from "pretext-harfbuzz";

// 1. Load the font, and let pretext measure with it through HarfBuzz.
const fonts = new FontBook();
fonts.add({ family: "Inter" }, await readFile("Inter-Regular.ttf"));
installHarfBuzzMeasurer(fonts, { locale: "en" });

// 2. Wrap the text at 200 px. How many lines, and how wide is the longest one?
const text = prepareWithSegments("Hello, headless world. No browser measured this.", "16px Inter");
const { lineCount, maxLineWidth } = measureLineStats(text, 200);
// lineCount = 2, so with 24 px lines the box is 48 px tall.
// maxLineWidth = 193.09375: the longest line is a bit narrower than 200 px.
